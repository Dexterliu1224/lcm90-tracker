# LCM90 视觉跟踪台

框选画面里的任意目标，让星特朗 LCM90 望远镜自动跟着它转。
不需要轨道数据、不需要知道目标是什么——**AI 视觉跟的是你框出来的那个东西**。

界面是深空风格的网页控制台：连接设备、框选目标、一键标定、开始跟踪，
全程有中文提示。

---

## 一分钟跑起来（不需要任何硬件）

```bash
python3 -m venv ~/.telescope-venv          # 已有可跳过
~/.telescope-venv/bin/pip install fastapi "uvicorn[standard]" opencv-python numpy pyyaml pyserial pillow
cd LCM90视觉跟踪
~/.telescope-venv/bin/python serve.py
```

会弹出一个**独立的程序窗口**（不是浏览器）。先用出厂账号 **admin / admin**
登录，进去后请立刻在右上角「修改密码」改掉。然后：

1. 望远镜下拉框选 **仿真基座** → 连接
2. 视频源下拉框选 **仿真画面** → 开启（会看到星空和一架移动的小飞机）
3. 在画面里**框一颗亮星** → 点「自动标定」（约 10 秒，望远镜自己动四下）
4. **框住小飞机** → 点「开始跟踪」——飞机会被一直摁在画面中心
5. 想留素材就点 **录制**，录的是带跟踪框和状态的画面，存在 `data/recordings/`

## 程序窗口 / 启动参数

默认就是一个桌面窗口，界面装在系统自带的 WebView 里（Windows 用 Edge
WebView2，macOS 用 WebKit）。关掉窗口即退出程序，退出时会自动停跟踪、
停基座、把录像文件收口。

| 参数 | 用处 |
|---|---|
| 无 | 桌面窗口（默认） |
| `--browser` | 退回浏览器打开，窗口起不来时用 |
| `--no-window` | 只跑服务，不开窗也不开浏览器（自动化、或从别的机器访问） |
| `--port 8400` | 换端口。**端口被占会自动顺延**，不用手动改 |
| `--verbose` | 打印每条请求，排查用 |
| `--check` | 自检 WebView 组件是否齐全后退出 |

**窗口打不开怎么办**：多半是这台 Windows 缺 Edge WebView2 运行时
（Win11 和多数 Win10 自带）。程序会自动退回浏览器模式并在窗口里说明原因，
装一次 [Evergreen Bootstrapper](https://go.microsoft.com/fwlink/p/?LinkId=2124703)
就好。打包版没有控制台，出错信息写在程序目录的 `data\app.log` 里。

## 识别星点（自动选星 + 对焦辅助）

点「识别星点」，画面里所有星点被自动圈出来，**点一下圆圈就选中为目标**，
不用再手动拖框。三种圈：

| 圈 | 含义 |
|---|---|
| 蓝色 | 正常星点，可点选 |
| 橙色虚线 | 过曝或太大（月亮、行星面、飞机），不适合当跟踪/标定点 |
| 绿色 + 「建议用它标定」 | 软件挑出的最佳标定星 |

**绿圈是重点**：它按「不过曝、够亮、周围没有邻星、离画面边缘够远」四条
挑出来。用它标定能避开最常见的那个坑 —— 框了会动或会被邻星勾走的目标，
解出来的矩阵方向是反的，而界面上一切正常。

面板上还会显示**星点锐度（FWHM，像素）**：转调焦座让这个数字变小，
到最小时焦点最准。这是天文观测里最实用的对焦方法。

用的是经典天文算法（背景估计 → 阈值分割 → 连通域 → 亮度加权质心），
不是神经网络：星点是几像素的点光源，没有形状特征，CNN 检测器在这上面
既慢又不准。经典算法 720p 一帧约 30ms、质心精度 0.03 像素、不占安装包体积。

## 登录与账号

- 出厂账号 **admin / admin**，第一次登录后界面会一直挂黄条提醒改密码。
- 口令按 PBKDF2-HMAC-SHA256 加盐散列存在 `data/users.json`，**不存明文**。
- admin 可以在「账号管理」里新建/删除账号、替人重置密码。
  普通账号能操作望远镜、改自己的密码，但管不了账号。
- 会话只存在内存里，程序一关全部失效。
- **忘记密码**：删掉 `data/users.json` 再启动，会重新生成 admin / admin。

## 录制

点「录制」开始，再点一次停止。录的是**带标注**的画面（跟踪框、准星环、
状态与误差读数），和你在网页上看到的完全一致，教学回放时学生能看懂
软件在做什么。

- 存放位置：`data/recordings/`，文件名是 `日期-时间-用户名.mp4`
- 帧率、目录、单段最长时长在 `config.yaml` 的 `recording` 段里改
- 默认最长录 60 分钟，到点自动停 —— 防止忘了关把磁盘写满
- 系统里没有 mp4 编码器时自动退回 `.avi`（MJPG），不会录不成

## 接真实硬件

### 望远镜（LCM90）

1. 手控器开机（跟踪这套流程**不需要** SkyAlign 校准，跳过也行）
2. NexStar 串口线插**手控器底部**的小方孔（不是基座的 AUX 口），另一头进电脑
3. 界面「望远镜」下拉框选出现的串口 → 连接
   - 连不上时界面会弹出逐条排查清单

### 相机（二选一，界面上就是那两个大按钮）

| 选项 | 接法 | 适合 |
|---|---|---|
| **目镜画面** | 行星相机（QHY 用 UVC 模式 / 任意 USB 相机）插在望远镜调焦座上 | 放大率高，适合精跟 |
| **外部相机** | 广角相机与镜筒并联同指向 | 视野大，容易先找到目标 |

选好后在下拉框挑摄像头 → 开启。QHY 相机需先装官方驱动并切到 UVC/相机模式，
或用任何能被系统识别为摄像头的设备。

### 使用流程（界面右下有步骤指引）

1. **标定（每套安装做一次）**：框一个**静止参照物**（远处建筑角、亮星），
   点「自动标定」。望远镜自己走四步，学会「画面偏移↔转轴方向」的换算，
   连相机装歪的角度和镜像都一并测出，结果存盘，重启不用重做。
2. **框选目标**：对着要跟的东西拖个框（飞机、卫星光点、无人机都行）。
3. **开始跟踪**：目标被持续摁回画面中心。丢失时基座立即停转并自动重捕。
4. 目标不在画面里？用右下角**手动微调**方向盘把它挪进来。

## 已验证 / 未验证

**仿真端到端已验证**：标定反解误差 <1%（5.98 vs 6.00 角秒/像素，
含转角与镜像判定）；连续跟踪 36 秒全程锁定，中位残差 5px，最大 22px；
目标被遮挡 10 帧能重捕；相机断流 0.5 秒内基座自动停转。

**未上过真机**：NexStar 串口协议按官方文档实现并有编码测试，
但真实手控器的时序差异只能现场验证。第一次接真机时，
先用手动微调按钮确认四个方向都动、方向正确，再做标定。

## 安全设计（这几条是硬编码的，不是配置）

- 目标丢失 → 基座速率**立即清零**（绝不带着旧速率盲转）
- 相机断流 0.5 秒 → 停转并提示
- 未标定 → 拒绝开始跟踪（方向未知时闭环会把目标越推越远）
- 停轴指令两轴独立下发（一轴失败不影响另一轴停下）

## 目录

```
serve.py            启动入口（python serve.py，--verbose 排查）
config.yaml         配置：串口、相机、PID、标定步长、账号与录制
core/
  mount.py          NexStar 协议 + 仿真基座（速率限制/加速度/齿隙）
  camera.py         UVC 相机 + 合成星空仿真（画面随指向变化，真闭环）
  tracker.py        框选目标跟踪（CSRT→模板匹配自动降级、置信度、重捕）
  calibration.py    四步自动标定（含移动中喂帧、目标漂移补偿、质量闸）
  control.py        状态机 + 双线程闭环 + 绝对速度前馈 PID
  auth.py           账号库（PBKDF2 加盐散列）+ 内存会话
  recorder.py       定频写视频（mp4→avi 自动降级、时长上限保护）
app/                FastAPI 后端 + 深空风格网页（含登录页）
tests/              回归测试（pytest；跑测试需要 httpx）
```

## 常见问题

| 现象 | 处理 |
|---|---|
| 跟踪时目标越修越远 | 标定过期（换过相机/转过相机）→ 重新标定 |
| 标定失败「目标丢失」 | 换更亮/更静止的参照物；调小 config 里 calibration.step_deg |
| 标定提示「目标自身移动较快」 | 换静止参照物重标（结果仍可用但精度打折） |
| 画面有但跟踪置信度低 | 框大一点、把目标框完整；目标太小换外部相机先粗跟 |
| 串口连不上 | 看界面弹窗的排查清单（线插手控器底部、驱动、占用） |
